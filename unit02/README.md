# Unit 2 practice: BGP communities refresher (offline)

A reading exercise. No router, lab or AWS account needed.

- `edge-router-policy.txt`: illustrative IOS-style route-maps that tag, match and act on communities.
- `routes.txt`: the routes the policy is applied to.
- `EXERCISE.md`: eight questions, answers at the end.
- `cloudwan-community-rule.json`: the Cloud WAN routing policy shown at the end of the unit. It is the community example from the AWS Cloud WAN blueprints (aws-samples on GitHub), shown for reading only.

All addresses use documentation ranges or private space; ASNs are private. The configuration has not been tested on a device; it shows the ideas, not a template.
